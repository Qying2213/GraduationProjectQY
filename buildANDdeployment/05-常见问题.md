# 常见问题 (FAQ)

## 1. CI/CD 相关问题

### Q1: GitHub Actions 构建失败，提示 "go mod download" 错误

**原因**: Go 模块依赖下载失败

**解决方案**:
```yaml
# 在 workflow 中添加缓存
- name: Cache Go modules
  uses: actions/cache@v4
  with:
    path: ~/go/pkg/mod
    key: ${{ runner.os }}-go-${{ hashFiles('**/go.sum') }}
```

### Q2: Docker 镜像推送失败

**原因**: Docker Hub 认证失败

**解决方案**:
1. 检查 `DOCKER_USERNAME` 和 `DOCKER_PASSWORD` Secrets 是否正确
2. 使用 Docker Hub Access Token 而不是密码
3. 在 Docker Hub 创建 Access Token: Settings → Security → New Access Token

### Q3: SSH 部署失败

**原因**: SSH 密钥配置错误

**解决方案**:
```bash
# 检查密钥格式
# 私钥应该以 -----BEGIN RSA PRIVATE KEY----- 开头

# 确保服务器上的 authorized_keys 权限正确
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

## 2. Docker 相关问题

### Q4: 容器启动后立即退出

**原因**: 应用程序崩溃或配置错误

**解决方案**:
```bash
# 查看容器日志
docker logs talent-resume-service

# 检查环境变量
docker exec talent-resume-service env

# 进入容器调试
docker exec -it talent-resume-service sh
```

### Q5: 数据库连接失败

**原因**: 数据库未就绪或网络问题

**解决方案**:
```yaml
# 在 docker-compose 中添加健康检查依赖
depends_on:
  postgres:
    condition: service_healthy
```

### Q6: 容器间无法通信

**原因**: 网络配置问题

**解决方案**:
```bash
# 检查网络
docker network ls
docker network inspect talent-network

# 确保所有服务在同一网络
networks:
  - talent-network
```

## 3. 服务相关问题

### Q7: AI 评估超时

**原因**: Coze API 响应时间较长

**解决方案**:
```go
// 增加超时时间
httpClient: &http.Client{Timeout: 300 * time.Second}
```

```nginx
# Nginx 配置增加超时
proxy_read_timeout 300s;
```

### Q8: Embedding 服务返回空向量

**原因**: API Key 未配置或配置错误

**解决方案**:
```bash
# 检查环境变量
echo $ARK_API_KEY

# 确保 .env 文件正确加载
docker exec talent-recommendation-service env | grep ARK
```

### Q9: 简历文件上传失败

**原因**: 文件大小限制或目录权限

**解决方案**:
```yaml
# docker-compose 中挂载卷
volumes:
  - resume_uploads:/app/uploads

# 检查目录权限
docker exec talent-resume-service ls -la /app/uploads
```

## 4. 数据库相关问题

### Q10: pgvector 扩展未安装

**原因**: 使用了普通 PostgreSQL 镜像

**解决方案**:
```yaml
# 使用 pgvector 镜像
postgres:
  image: pgvector/pgvector:pg16
```

### Q11: 数据库迁移失败

**原因**: 表结构冲突

**解决方案**:
```bash
# 手动执行迁移
docker exec -it talent-postgres psql -U qinyang -d talent_platform

# 检查表结构
\dt
\d+ resumes
```

## 5. 性能相关问题

### Q12: 服务响应缓慢

**原因**: 资源不足或数据库查询慢

**解决方案**:
```bash
# 检查资源使用
docker stats

# 检查数据库慢查询
docker exec talent-postgres psql -U qinyang -d talent_platform -c "
SELECT query, calls, mean_time 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;"
```

### Q13: 内存占用过高

**原因**: 容器内存限制未设置

**解决方案**:
```yaml
# docker-compose 中设置资源限制
services:
  resume-service:
    deploy:
      resources:
        limits:
          memory: 512M
        reservations:
          memory: 256M
```

## 6. 安全相关问题

### Q14: 如何保护敏感信息

**解决方案**:
1. 使用 GitHub Secrets 存储敏感信息
2. 不要将 `.env` 文件提交到 Git
3. 使用环境变量而不是硬编码

```bash
# .gitignore
.env
*.pem
*.key
```

### Q15: 如何配置 HTTPS

**解决方案**:
```bash
# 使用 Let's Encrypt
sudo certbot --nginx -d your-domain.com

# 或使用自签名证书（仅测试）
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/nginx/ssl/privkey.pem \
  -out /etc/nginx/ssl/fullchain.pem
```
