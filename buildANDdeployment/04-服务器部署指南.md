# 服务器部署指南

## 1. 服务器要求

### 1.1 最低配置
- CPU: 2 核
- 内存: 4 GB
- 硬盘: 50 GB SSD
- 系统: Ubuntu 20.04+ / CentOS 7+

### 1.2 推荐配置
- CPU: 4 核
- 内存: 8 GB
- 硬盘: 100 GB SSD
- 系统: Ubuntu 22.04 LTS

## 2. 服务器初始化

### 2.1 安装 Docker

```bash
# Ubuntu
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker --version
docker-compose --version
```

### 2.2 配置防火墙

```bash
# Ubuntu (UFW)
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw allow 8080/tcp  # Gateway
sudo ufw enable

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

### 2.3 创建部署目录

```bash
sudo mkdir -p /opt/talent-platform
sudo chown $USER:$USER /opt/talent-platform
cd /opt/talent-platform
```

## 3. 配置 SSH 密钥

### 3.1 在本地生成 SSH 密钥

```bash
ssh-keygen -t rsa -b 4096 -C "deploy@talent-platform" -f ~/.ssh/deploy_key
```

### 3.2 将公钥添加到服务器

```bash
# 复制公钥内容
cat ~/.ssh/deploy_key.pub

# 在服务器上添加
echo "公钥内容" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### 3.3 将私钥添加到 GitHub Secrets

将 `~/.ssh/deploy_key` 的内容添加到 GitHub Secrets 的 `SERVER_SSH_KEY`

## 4. 部署脚本

### 4.1 创建部署脚本 (deploy.sh)

```bash
#!/bin/bash
# /opt/talent-platform/deploy.sh

set -e

echo "=========================================="
echo "智能招聘系统 - 自动部署脚本"
echo "=========================================="

cd /opt/talent-platform

# 拉取最新代码
echo ">>> 拉取最新代码..."
git pull origin main

# 拉取最新镜像
echo ">>> 拉取最新镜像..."
docker-compose -f docker-compose.prod.yml pull

# 停止旧容器
echo ">>> 停止旧容器..."
docker-compose -f docker-compose.prod.yml down

# 启动新容器
echo ">>> 启动新容器..."
docker-compose -f docker-compose.prod.yml up -d

# 清理旧镜像
echo ">>> 清理旧镜像..."
docker image prune -f

# 等待服务启动
echo ">>> 等待服务启动..."
sleep 10

# 健康检查
echo ">>> 健康检查..."
for port in 8080 8081 8082 8083 8084 8085 8086 8087; do
    status=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:$port/health)
    if [ "$status" = "200" ]; then
        echo "  端口 $port: ✓ 正常"
    else
        echo "  端口 $port: ✗ 异常 (HTTP $status)"
    fi
done

echo "=========================================="
echo "部署完成!"
echo "=========================================="
```

### 4.2 设置执行权限

```bash
chmod +x /opt/talent-platform/deploy.sh
```

## 5. Nginx 反向代理配置

### 5.1 安装 Nginx

```bash
sudo apt update
sudo apt install nginx -y
```

### 5.2 配置文件 (/etc/nginx/sites-available/talent-platform)

```nginx
upstream gateway {
    server 127.0.0.1:8080;
}

upstream frontend {
    server 127.0.0.1:80;
}

server {
    listen 80;
    server_name your-domain.com;
    
    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # SSL 证书
    ssl_certificate /etc/nginx/ssl/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/privkey.pem;
    
    # SSL 配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;

    # 前端
    location / {
        proxy_pass http://frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API 网关
    location /api/ {
        proxy_pass http://gateway;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 300s;  # AI 评估需要较长时间
    }

    # 健康检查
    location /health {
        proxy_pass http://gateway/health;
    }
}
```

### 5.3 启用配置

```bash
sudo ln -s /etc/nginx/sites-available/talent-platform /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 7. 监控和日志

### 7.1 查看容器日志

```bash
# 查看所有日志
docker-compose -f docker-compose.prod.yml logs -f

# 查看特定服务
docker-compose -f docker-compose.prod.yml logs -f resume-service

# 查看最近 100 行
docker-compose -f docker-compose.prod.yml logs --tail=100 gateway
```

### 7.2 设置日志轮转

```bash
# /etc/docker/daemon.json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
```

### 7.3 监控脚本 (monitor.sh)

```bash
#!/bin/bash

echo "=========================================="
```

## 8. 备份策略

### 8.1 数据库备份脚本 (backup.sh)

```bash
#!/bin/bash
# /opt/talent-platform/backup.sh

BACKUP_DIR="/opt/backups"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/talent_platform_$DATE.sql.gz"

mkdir -p $BACKUP_DIR

# 备份数据库
docker exec talent-postgres pg_dump -U qinyang talent_platform | gzip > $BACKUP_FILE

# 保留最近 7 天的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete

echo "备份完成: $BACKUP_FILE"
```

### 8.2 设置定时备份

```bash
# 编辑 crontab
crontab -e

# 每天凌晨 2 点备份
0 2 * * * /opt/talent-platform/backup.sh >> /var/log/backup.log 2>&1
```

## 9. 故障恢复

### 9.1 恢复数据库

```bash
# 解压备份文件
gunzip talent_platform_20260123.sql.gz

# 恢复数据库
cat talent_platform_20260123.sql | docker exec -i talent-postgres psql -U qinyang -d talent_platform
```

### 9.2 重启服务

```bash
# 重启所有服务
docker-compose -f docker-compose.prod.yml restart

# 重启单个服务
docker-compose -f docker-compose.prod.yml restart resume-service
```
