# 智能人才运营平台 - 快速启动指南

## 环境要求

- Go 1.21+
- Node.js 18+
- PostgreSQL 14+
- Redis 7+ (可选)
- Elasticsearch 8+ (可选，用于日志)

## 一、数据库初始化

### 1. 启动 PostgreSQL
```bash
# macOS
brew services start postgresql

# 或手动启动
pg_ctl -D /usr/local/var/postgres start
```

### 2. 创建数据库
```bash
# 创建数据库
createdb talent_platform

# 初始化表结构和测试数据
psql -d talent_platform -f backend/database/schema.sql
psql -d talent_platform -f backend/database/mock_data.sql
```

或使用初始化脚本：
```bash
chmod +x init-db.sh
./init-db.sh
```

## 二、配置环境变量

复制环境变量模板：
```bash
cp backend/.env.example backend/.env
```

编辑 `backend/.env` 文件，配置以下变量：
```bash
# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_USER=qinyang
DB_PASSWORD=
DB_NAME=talent_platform

# AI服务配置（可选）
COZE_API_TOKEN=your_coze_token
COZE_WORKFLOW_ID=your_workflow_id
COZE_ATTRIBUTION_WORKFLOW_ID=your_attribution_workflow_id

# 火山引擎Embedding配置（可选）
VOLC_ACCESS_KEY=your_access_key
VOLC_SECRET_KEY=your_secret_key
VOLC_EMBEDDING_MODEL=doubao-embedding
```

## 三、启动服务

### 方式一：使用启动脚本（推荐）

```bash
chmod +x start-all.sh
./start-all.sh
```

这将在独立的终端窗口中启动所有微服务。

### 方式二：手动启动

在不同终端窗口中分别执行：

```bash
# 终端1 - Gateway (8080)
cd backend/gateway && go run main.go

# 终端2 - User Service (8081)
cd backend/user-service && go run main.go

# 终端3 - Job Service (8082)
cd backend/job-service && go run main.go

# 终端4 - Interview Service (8083)
cd backend/interview-service && go run main.go

# 终端5 - Resume Service (8084)
cd backend/resume-service && go run main.go

# 终端6 - Message Service (8085)
cd backend/message-service && go run main.go

# 终端7 - Talent Service (8086)
cd backend/talent-service && go run main.go

# 终端8 - Recommendation Service (8087)
cd backend/recommendation-service && go run main.go
```

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

## 六、功能模块

### 核心功能
- **人才管理**: 人才信息录入、查询、状态管理
- **职位管理**: 职位发布、编辑、状态管理
- **简历管理**: 简历上传、解析、状态跟踪
- **面试管理**: 面试安排、反馈、日历视图
- **智能推荐**: 人岗匹配、语义搜索

### AI功能
- **简历智能解析**: OCR + 大模型提取简历信息
- **人岗智能匹配**: 语义向量化 + 多维度匹配
- **归因报告生成**: 可解释的推荐理由与建议
- **评估结果管理**: 查看和管理所有AI评估记录

## 八、常见问题

### 1. 数据库连接失败
确保 PostgreSQL 正在运行：
```bash
pg_isready
```

### 2. 端口被占用
查找并终止占用端口的进程：
```bash
lsof -i :8080
kill -9 <PID>
```

### 3. Go模块下载失败
设置 Go 代理：
```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

### 4. 前端依赖安装失败
清除缓存重试：
```bash
rm -rf node_modules package-lock.json
npm install
