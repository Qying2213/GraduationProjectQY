# 智能人才运营平台 - 快速启动指南

本指南面向答辩演示、本地联调和论文复现实验，目标是在最短时间内把系统跑起来。

## 一、环境要求

| 软件 | 版本要求 | 必需 |
|---|---|---|
| Go | 1.21+ | 是 |
| Node.js | 18+ | 是 |
| PostgreSQL | 14+ | 是 |
| Redis | 7+ | 建议 |
| Elasticsearch | 8+ | 可选 |
| Docker / Docker Compose | 20+ | 可选 |

## 二、初始化数据库

推荐直接在项目根目录执行：

```bash
./init-db.sh
```

如果需要手动执行：

```bash
createdb talent_platform
psql -d talent_platform -f backend/databaseSQL/schema.sql
psql -d talent_platform -f backend/databaseSQL/init_data.sql
```

## 三、配置环境变量

复制模板：

```bash
cp backend/.env.example backend/.env
```

按需修改 `backend/.env`：

```bash
# 数据库
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=talent_platform
DB_SSLMODE=disable

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379

# Elasticsearch
ES_URL=http://localhost:9200

# JWT
JWT_SECRET=change-me-in-production

# Coze
COZE_BASE_URL=https://api.coze.cn
COZE_TOKEN=your_coze_token
COZE_WORKFLOW_ID=your_workflow_id
COZE_API_TOKEN=your_other_coze_token_if_needed
COZE_ATTRIBUTION_WORKFLOW_ID=your_attribution_workflow_id

# Embedding
VOLC_ENDPOINT=https://ark.cn-beijing.volces.com/api/v3/embeddings/multimodal
ARK_API_KEY=your_ark_api_key
VOLC_MODEL_ID=doubao-embedding-vision-251215
```

说明：

- `resume-service` 当前主要使用 `COZE_TOKEN + COZE_WORKFLOW_ID`
- 推荐归因等其他链路兼容使用 `COZE_API_TOKEN + COZE_ATTRIBUTION_WORKFLOW_ID`

## 四、启动系统

### 方式一：一键启动开发环境

```bash
./start-all.sh
```

启动后可访问：

- 开发面板：`http://localhost:8091`
- 管理后台：`http://localhost:5173/login`
- 求职者门户：`http://localhost:5173/portal`
- 数据大屏：`http://localhost:5173/data-screen`
- API 网关：`http://localhost:8080/api/v1`

停止：

```bash
./stop-all.sh
```

### 方式二：手动逐个启动

```bash
# Gateway
cd backend/gateway && go run main.go

# User Service
cd backend/user-service && go run main.go

# Job Service
cd backend/job-service && go run main.go

# Interview Service
cd backend/interview-service && go run main.go

# Resume Service
cd backend/resume-service && go run main.go

# Message Service
cd backend/message-service && go run main.go

# Talent Service
cd backend/talent-service && go run main.go

# Recommendation Service
cd backend/recommendation-service && go run main.go

# Log Service
cd backend/log-service && go run main.go

# Evaluator Service
cd backend/evaluator-service && go run ./cmd/server
```

前端：

```bash
cd frontend
npm install
npm run dev
```

## 九、常见问题

### 1. 数据库连接失败

```bash
pg_isready
```

### 2. 端口被占用

```bash
lsof -i :8080
kill -9 <PID>
```

### 3. Go 依赖下载慢

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

### 4. 前端依赖安装失败

```bash
rm -rf node_modules package-lock.json
npm install
```
