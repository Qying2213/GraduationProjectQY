## 3. 可复现实验步骤（答辩前建议执行）

```bash
# 1) 启动基础依赖
docker compose up -d postgres redis elasticsearch

# 2) 初始化数据库
./init-db.sh

# 3) 启动后端微服务
./start-all.sh

# 4) 启动前端
cd frontend && npm install && npm run dev
```

## 4. 测试命令

```bash
# 前端单元测试（默认不跑集成接口）
cd frontend && npm test -- --run

# 前端 API 集成测试（需后端服务已启动）
cd frontend && npm run test:integration

# 全链路接口测试脚本
cd ztest && ./run_all_tests.sh
```

## 5. 性能验收建议

1. 启动全系统后执行 `./scripts/benchmark.sh`。
2. 将输出结果填入 `docs/性能测试报告.md` 中的指标表。
3. 保留压测原始日志与报告截图，用于答辩时作为“1000 QPS 与延迟指标”的证据。

## 6. 答辩演示建议顺序

1. 管理端登录与权限切换（RBAC）。
2. 职位发布 -> 简历管理 -> AI 评估。
3. 人岗推荐结果与推荐理由展示（可解释性）。
4. 面试日历与消息通知流程。
5. 数据大屏展示招聘指标。
