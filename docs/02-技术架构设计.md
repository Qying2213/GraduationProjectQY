# 技术架构设计

## 整体架构

系统采用前后端分离 + 微服务架构模式。

### 后端框架
- **语言**: Go 1.21+
- **Web框架**: Gin
- **ORM**: GORM
- **通信**: HTTP REST / gRPC

### Elasticsearch (日志检索)
- 操作日志存储
- 全文检索
- 系统监控

## 高并发设计

### Goroutine并发模型
```go
// 并发处理简历解析
func (h *ResumeHandler) BatchParseResumes(resumes []Resume) {
    var wg sync.WaitGroup
    results := make(chan ParseResult, len(resumes))
    
    for _, resume := range resumes {
        wg.Add(1)
        go func(r Resume) {
            defer wg.Done()
            result := h.parseResume(r)
            results <- result
        }(resume)
    }
    
    wg.Wait()
    close(results)
}
```

### 多级缓存策略
```
请求 → 本地缓存(sync.Map) → Redis缓存 → 数据库
         ↓ 命中              ↓ 命中        ↓
       直接返回            直接返回      查询并回填缓存
```

### 连接池复用
- 数据库连接池: MaxOpenConns=100, MaxIdleConns=10
- Redis连接池: PoolSize=100
- HTTP客户端复用
