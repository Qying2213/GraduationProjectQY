## 4. 本轮发现并解决的问题

1. 前端集成测试初始化失败（登录 401）
- 根因：测试脚本写死 `admin/admin123`，环境数据不保证存在。
- 修复：`frontend/src/__tests__/api.test.ts` 增加“admin 登录失败 -> 自动注册临时测试用户 -> 登录”回退机制。

2. 前端集成测试详情用例失败（404）
- 根因：测试数据为空时，`/interviews/1`、`/resumes/1`、`/talents/1` 不存在。
- 修复：改为“先查列表拿真实 id；无数据时断言 404”。

3. 8090 外部访问受限
- 根因：当前在线容器的历史端口映射为 `8080-8088`，不含 `8090`。
- 当前状态：容器内 `evaluator-service` 进程可运行，但宿主机直连 `localhost:8090` 不可用。
- 建议：答辩前重建 `backend` 容器并应用 `docker-compose.yml` 中 `8090:8090` 映射，以开放外部访问。
