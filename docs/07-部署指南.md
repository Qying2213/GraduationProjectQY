# 部署指南

本指南用于说明毕业设计项目在本地、服务器和 Docker 环境中的部署方式。

## 一、部署目标

部署后的系统应至少满足以下条件：

- 前端管理后台、求职者门户、数据大屏可访问
- API 网关与核心微服务可正常调用
- AI 评估链路可访问 Coze 工作流
- 推荐、日志、消息等辅助能力可正常工作

## 二、环境要求

### 1. 硬件建议

- CPU：4 核及以上
- 内存：8GB 及以上
- 磁盘：50GB 及以上

### 2. 软件依赖

| 软件 | 版本建议 |
|---|---|
| Go | 1.21+ |
| Node.js | 18+ |
| PostgreSQL | 14+ |
| Redis | 7+ |
| Elasticsearch | 8+ |
| Docker | 20+ |
| Docker Compose | 2.x |

## 三、Docker Compose 部署

### 1. 准备环境变量

```bash
cp backend/.env.example backend/.env
```

建议重点检查以下变量：

```bash
DB_HOST=postgres
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=talent_platform
DB_SSLMODE=disable

REDIS_HOST=redis
REDIS_PORT=6379

JWT_SECRET=your_jwt_secret

COZE_BASE_URL=https://api.coze.cn
COZE_TOKEN=your_coze_token
COZE_WORKFLOW_ID=your_workflow_id
COZE_API_TOKEN=your_other_coze_token_if_needed
COZE_ATTRIBUTION_WORKFLOW_ID=your_attribution_workflow_id

VOLC_ENDPOINT=https://ark.cn-beijing.volces.com/api/v3/embeddings/multimodal
ARK_API_KEY=your_ark_api_key
VOLC_MODEL_ID=doubao-embedding-vision-251215
```

### 2. 启动容器

```bash
docker compose up -d --build
```

### 3. 初始化数据库

如果是首次部署，建议执行：

```bash
./init-db.sh
```

当前数据库脚本位于：

- `backend/databaseSQL/schema.sql`
- `backend/databaseSQL/init_data.sql`

### 4. 检查服务

```bash
docker compose ps
curl http://localhost:8080/health
curl http://localhost:8081/health
curl http://localhost:8082/health
curl http://localhost:8083/health
curl http://localhost:8084/health
curl http://localhost:8085/health
curl http://localhost:8086/health
curl http://localhost:8087/health
curl http://localhost:8088/health
curl http://localhost:8090/
```

说明：

- `docker-compose.yml` 当前已包含 `8090:8090` 映射
- 如果宿主机无法直连 `8090`，通常意味着运行中的容器仍是旧实例，需重建：

```bash
docker compose down
docker compose up -d --build
```

## 四、手动部署

### 1. 安装依赖

```bash
for svc in gateway user-service job-service interview-service resume-service message-service talent-service recommendation-service log-service evaluator-service; do
  (cd backend/$svc && go mod tidy)
done

cd frontend
npm install
```

### 2. 初始化数据库

```bash
createdb talent_platform
psql -d talent_platform -f backend/databaseSQL/schema.sql
psql -d talent_platform -f backend/databaseSQL/init_data.sql
```

### 3. 启动后端服务

推荐方式：

```bash
./start-all.sh
```

或逐个启动：

```bash
cd backend/gateway && go run main.go &
cd backend/user-service && go run main.go &
cd backend/job-service && go run main.go &
cd backend/interview-service && go run main.go &
cd backend/resume-service && go run main.go &
cd backend/message-service && go run main.go &
cd backend/talent-service && go run main.go &
cd backend/recommendation-service && go run main.go &
cd backend/log-service && go run main.go &
cd backend/evaluator-service && go run ./cmd/server &
```

### 4. 启动前端

```bash
cd frontend
npm run dev
```

## 八、常见问题

### 1. 服务启动失败

```bash
lsof -i :8080
docker compose logs -f
```

### 2. 数据库连接失败

重点检查：

- `backend/.env`
- PostgreSQL 账号密码
- `DB_HOST` 是否与部署方式一致

### 3. AI 评估不可用

重点检查：

- `COZE_TOKEN`
- `COZE_WORKFLOW_ID`
- `ARK_API_KEY`
- 外网是否可访问 Coze 与火山引擎接口

### 4. 8090 无法访问

确认：

```bash
docker compose ps
docker compose down
docker compose up -d --build
```

如果容器是旧实例，新的端口映射不会自动应用。
