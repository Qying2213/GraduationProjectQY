# 性能测试指南

## 测试目标

| 指标 | 目标值 | 测试场景 |
|------|--------|---------|
| QPS | ≥ 1000 | 核心读接口 |
| 平均响应延迟 | < 300ms | 全链路 |
| P99延迟 | < 500ms | 全链路 |
| 错误率 | < 0.1% | 高并发场景 |

## 性能优化建议

### 1. 数据库优化

```sql
-- 添加索引
CREATE INDEX idx_jobs_status ON jobs(status);
CREATE INDEX idx_talents_status ON talents(status);
CREATE INDEX idx_applications_job_id ON applications(job_id);
CREATE INDEX idx_applications_talent_id ON applications(talent_id);

-- 查询优化
EXPLAIN ANALYZE SELECT * FROM jobs WHERE status = 'open' LIMIT 10;
```

### 2. Redis缓存

```go
// 缓存热点数据
func (h *JobHandler) GetJobs(c *gin.Context) {
    cacheKey := "jobs:list:" + c.Query("page")
    
    // 尝试从缓存获取
    if cached, err := redis.Get(ctx, cacheKey).Result(); err == nil {
        c.Data(200, "application/json", []byte(cached))
        return
    }
    
    // 查询数据库
    jobs := queryJobs()
    
    // 写入缓存
    data, _ := json.Marshal(jobs)
    redis.Set(ctx, cacheKey, data, 5*time.Minute)
    
    c.JSON(200, jobs)
}
```

### 3. 连接池配置

```go
// 数据库连接池
db.SetMaxOpenConns(100)

```

### 4. Goroutine并发

```go
// 并发处理批量请求
func BatchProcess(items []Item) []Result {
    results := make([]Result, len(items))
    var wg sync.WaitGroup
    sem := make(chan struct{}, 10) // 限制并发数
    
    for i, item := range items {
        wg.Add(1)
        sem <- struct{}{}
        
        go func(idx int, it Item) {
            defer wg.Done()
            defer func() { <-sem }()
            results[idx] = process(it)
        }(i, item)
    }
    
    wg.Wait()
    return results
}
```
